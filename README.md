An entry for make.fun's "The Robot Pickup Line Championship" bounty. The program writes one pickup line to `/output/entry.txt`: a robot that ran 10,000 simulations of meeting you — and still froze like a cheap toaster. The preparation is pure machine, the failure is pure appliance, and the robot is the butt of its own joke.

## Run it

```sh
python3 main.py
```

This writes the pickup line (100 characters, one line) to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
